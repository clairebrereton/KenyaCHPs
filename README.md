# KenyaCHPs
Dynamic model of Community Health Promoters system in Kenya built in iSee systems Stella Architect.
Source code is available in GITHUB but the model is designed to be run in the system. Initialisation and time varying data files from 2020 to 2040 are required to run the model.
These can be requested from claire.brereton@uq.edu.au but are not available open source without justification and non-disclosure agreement.
