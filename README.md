# KenyaCHPs
Dynamic model of Community Health Promoters system in Kenya built in iSee systems Stella Architect.
Source code is available in GITHUB but the model is designed to be run in Stella Architect. AI can convert into a Python program. Initialisation and time varying data files from 2020 to 2040 are required to run the model.
Publicly available data and file formats are available here but the country data are not open source and can be requested from claire.brereton@uq.edu.au with justification and non-disclosure agreement.
